# 重型车辆发动机部件：设备、测量与工况

车辆来自日常运营的重型卡车车队，目标为发动机内一个因商业保密而未公开名称的部件。车辆是访问制造商官方维修网络且具有完整维修记录的随机子集。车队包含不同使用条件。原始车辆编号、真实日期、部件名称和变量物理名称未公开，不能把相对时间换算为天、小时或行驶里程。

运行数据由车载传感器和电子控制单元采集，通常经远程通信或维修站插线读取。读数是不规则、非等间隔的稀疏时间序列；一个读数描述相邻采集时点之间所记录的信息。特征主要是累计计数和直方图。电子控制单元更新软件时计数器可能重置；设备方作过后处理，但不能保证所有异常均已处理。

原始运行变量由领域专家从全部可用变量中选取，共14个变量。六个变量展开为直方图：`hist_01`有10个分箱、`hist_02`有10个、`hist_03`有11个、`hist_04`有10个、`hist_05`有20个、`hist_06`有36个。列名最后两位为从0开始的分箱索引。其余八列 `counter_01` 至 `counter_08` 是单个数值计数器。合计105列。

直方图各箱对应测量量的某一区间或条件；分箱依据可以包括变量范围、测量分辨率、专家知识和行业标准，两端可能开放。设备方用“不同温度范围下的行驶距离累计”举例说明直方图含义，但这不是本数据任一具体变量的已知物理解释。具体各变量名称、单位、分箱边界、多维直方图轴含义及传感器标定未公开。来源描述这些量大多具有累积性，可反映随时间的变化；不能据此保证每个计数器在所有记录中严格单调。

车辆规格来自生产系统，八个匿名类别变量 `spec_01` 至 `spec_08` 对应原始规格列表的顺序。来源举出的规格种类包括发动机类型、车轮配置、重量容量和尺寸，但未公开各匿名列分别对应什么。类别采用 Cat0、Cat1 等符号；符号中的数字不意味着物理大小或顺序。罕见情况下车辆改装后规格可能与生产时记录不一致。

维修记录来自服务发票和工单：目标部件被更换或标为已维修时，来源将其作为失效事件；只能获取官方网络内的服务信息。训练事件时刻是原厂安装部件开始使用以来的首次维修时刻。没有事件的车辆只知道在观察期内未维修，其后状态未知。

为了匿名化，原始时间被替换为相对时间，并对运行值作过缩放等扰动；维修频率和读数频率可能被修改，因此不能把数据中的比例直接解释成真实车队发生率。来源声称这些处理保留了时间模式和建模用途，但未公开逐列变换参数。匿名化车辆标识在各表间保持一致。

缺失可能来自未安装某传感器、控制单元未开启信号记录或通信问题。来源报告运行变量每列缺失率低于1%，规格和维修记录无缺失；该描述不构成逐值正确性的保证。资料没有提供具体车型、部件失效机理、载荷工况的真实单位或可通用的维修阈值。
